Primero qué va en cada pantalla y en qué orden. Luego lo ves navegable, no en una imagen plana. Si la estructura falla, el diseño no la salva.

  • Estructura y wireframes
  • Diseño de interfaz
  • Prototipo navegable
  • Versión móvil

Lo monto yo. Lo que ves en el diseño es lo que acaba en pantalla. Si pides WordPress, va con WordPress; si hace falta un plugin concreto, se mira y se mete.

  • Maquetación HTML / CSS / JS
  • WordPress a medida
  • Plugins cuando hacen falta
  • Publicación y dominio

Ya tienes web pero se ha quedado vieja, va lenta o la gente no encuentra lo que busca. Miro qué falla de verdad, qué merece quedarse y rehago el resto.

  • Revisión de lo que hay
  • Qué se mantiene y qué cambia
  • Nueva interfaz
  • Migración sin líos

Cuando la web tiene que hacer algo más que enseñar: reservar, pedir cita o pagar. Monto el flujo entero y lo pruebo hasta que no se atasca.

  • Reservas y citas
  • Formularios que llegan
  • Pagos online
  • Pruebas del flujo completo

Herramientas internas: paneles que controlan varias webs, zonas privadas, flujos de WhatsApp Business o mail. No son plantillas; se montan para lo que necesitas tú.

  • Paneles de control
  • Apps a medida
  • Zonas privadas
  • Integraciones (WhatsApp, mail…)

Piezas para la web y para los anuncios: imagen, vídeo y variaciones para probar qué funciona. También como servicio suelto, no solo metido dentro de un proyecto web.

  • Imagen y visuales
  • Vídeo
  • Creatividades para campañas
  • Variaciones para testear
